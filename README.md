# 🎭 Carnaval de Barranquilla — Sitio Web Institucional

> Proyecto académico de diseño gráfico y desarrollo front-end dedicado a la difusión cultural del Carnaval de Barranquilla ("Detrás de la máscara").

## 📖 Sobre el proyecto
Este sitio web fue desarrollado como parte de un proyecto universitario de diseño gráfico. Su objetivo principal es consolidar los conocimientos en maquetación web, jerarquía tipográfica, diseño UI/UX y optimización de interfaces. 

El sitio rinde homenaje a la tradición, la alegría y el folclore del Caribe colombiano, estructurando la información de manera visualmente atractiva, accesible y responsiva.

## ✨ Características principales
* **Diseño UI/UX Temático:** Paleta de colores inspirada en la festividad (Púrpura, Naranja y Verde) y uso de tipografías personalizadas.
* **Estructura Multitarea (4 páginas):**
  * **Inicio:** Presentación de la festividad y bienvenida.
  * **El Carnaval:** Historia, orígenes y elementos culturales clave.
  * **Agenda:** Programación de eventos y actividades oficiales.
  * **Comunidad:** Espacio participativo y de contacto para los asistentes.
* **Desarrollo Front-End Nativo:** Maquetado completamente en **HTML5** y **CSS puro**, utilizando tecnologías modernas de diseño flexible sin dependencias de JavaScript ni frameworks externos.
* **Interactividad Responsiva:** Menú de navegación adaptable para dispositivos móviles mediante un sistema de control CSS nativo (`:checked`).

## 🛠️ Tecnologías utilizadas
* **HTML5:** Estructuración semántica del contenido.
* **CSS3:** Estilos avanzados, Flexbox, media queries y diseño responsivo.
* **Control de versiones:** Git & GitHub.
